SpaceDyn as a MATLAB toolbox

SpaceDyn was originally created as MATLAB toolbox to handle the dynamics of space robotics such as free-flying robots and mobile vehecles for planetary exploration.

The interactive quick start guide written in html is already available in our GitHub directory.

Please download the repository spacedyn_reference and open index.html in web browser to get started.
